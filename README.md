## 🔬 Research

- **FedMedChain** — reputation-weighted federated learning with blockchain incentives on a real three-machine LAN. 96% global accuracy, with a cosine-similarity detector for poisoned updates.
- **Mobile-friendly MaxViT** — distilled models for on-device skin-lesion classification via CoreML. 82.74% macro F1 with a 49.43% smaller model.
- **Yet Another Game-N-Gen** — self-supervised multi-game simulation from video frames and action tokens using modified Stable Diffusion.
